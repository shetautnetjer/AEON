Reuse **Hermes's existing OTel provider → a separate local Alloy receiver → Tempo → Grafana**, with **Prometheus beside it for metrics**. Start with synthetic turns/tool/error/memory-decision fixtures; real-session capture follows explicit acceptance. These roles follow the parent's [official local Tempo review](https://grafana.com/docs/tempo/latest/set-up-for-tracing/setup-tempo/deploy/locally/); local files below govern what currently exists.

- [Custom span API](/home/aya-hmw/.hermes/plugins/hermes_otel/tracer.py:1595) accepts explicit session/parent, with [SpanTracker](/home/aya-hmw/.hermes/plugins/hermes_otel/span_tracker.py:145) maintaining session-keyed stacks. - **Context gap:** starting a span with an explicit parent does not attach that parent to OTel's current context. Auto-instrumentors can therefore produce unrelated roots even with the same provider. Bridge only the actual same-thread SDK invocation to its existing API parent and detach in `finally`; test concurrent sessions, retries and streaming. Managed Hermes `agent/chat_completion_helpers.py`, `agent/turn_api_request.py` and `agent/turn_response_intake.py` own dispatch; they are runtime source, not permission to modify all managed installs.
- **Content gap:** content-off does not guard [tool command/target](/home/aya-hmw/.hermes/plugins/hermes_otel/hooks/tools.py:173), [turn rollups](/home/aya-hmw/.hermes/plugins/hermes_otel/hooks/attributes.py:250), [tool error text](/home/aya-hmw/.hermes/plugins/hermes_otel/hooks/tools.py:266) or API exception messages. A small explicit export allowlist must omit these fields before real capture. Also omit raw stop-sequence text, skill paths and failed-subagent summaries. Normalize approval span names to fixed `approval`: [approval names](/home/aya-hmw/.hermes/plugins/hermes_otel/hooks/approval.py:75) embed free-form command fragments. Validate span/event names and allowed values as well as attribute keys; flags or attribute filtering alone cannot protect arbitrary names/status descriptions. Also explicitly disable the currently default-on `dashboard_live` storage; metrics/logs-off alone is insufficient.
- **Memory/decision gap:** [Brainstem adapter](/home/aya-hmw/Documents/ChatGPT/AEON/worktrees/brainstem-continuation/adapter.py:38) and [catalog lookup](/home/aya-hmw/Documents/ChatGPT/AEON/worktrees/brainstem-continuation/catalog_read.py:54) expose lookup/context-planning metadata, not qualified memory recall. [Jev run_hook](/home/aya-hmw/aya/projects/jev-cli/src/jev_cli/hooks.py:67) owns actual contract/run/step/status/replay/evaluation metadata. Completion is distinct from an independently verified outcome. Instrument actual memory operations at their source owner only after its invocation/correlation contract is mapped; never fabricate a session parent or infer decisions from text.

Initially keep Hermes `api.*` as the canonical model-attempt metric source. Add one selected OpenAI instrumentor only after the provider/context/privacy tests pass; other instrumentors require an actual provider need. If SDK spans become canonical invocation metrics, count those spans only, leaving the API wrapper as an envelope. Prove no duplicate peers/counts across success, streaming, retry and failure. Do not activate the candidate identity lab alongside Hermes: it emits separate synthetic roots, not proven continuity.

## Metadata contract for the pilot

| Keep in traces, where actually supplied | Omit by default |
|---|---|
| Native trace/span/parent IDs, timing, status; existing `session.id`, `gen_ai.conversation.id`, `hermes.turn.number`; actual tool call/correlation IDs | Sender/user names, message bodies, prompts, completions, hidden reasoning, tool arguments/results, command/target/path rollups, embedding inputs/vectors |
| Provider/model/operation, token counts, tool name, bounded outcome/error type/status/retry count | Raw exception messages/descriptions/events, request URLs/headers, arbitrary resource tags or unsanitized error strings |
| Source-owned contract/version/run/step, replay and evaluation-attempt flags; lookup/eligibility/abstention/verification result codes when actually emitted | New actor/binding identities, inferred intent/reasons, source document contents or an assertion that advisory catalog planning is accepted recall |

New telemetry mappings remain trace-local descriptions of existing source contracts, not a replacement Dictionary/schema taxonomy. Session/trace/run/record IDs belong in traces, **never Prometheus labels**. Metric dimensions stay bounded: service/environment, operation/tool category, approved provider/model family and outcome/status. Disable automatic resource-to-label conversion; review actual emitted series.

Explicitly set native Hermes `content_capture: off`, `capture_sender_id: false` and `dashboard_live: false`; disable previews/history/logs and review native metrics/export/profile overrides before synthetic startup. Hermes does not consume the instrumentor flag and its native content default is full. Use `TRACELOOP_TRACE_CONTENT=false`. Selected instrumentors reuse Hermes's provider; no default full-SDK initialization, default external endpoint or anonymous Traceloop telemetry. These constraints derive from the parent's [without-SDK](https://www.traceloop.com/docs/openllmetry/tracing/without-sdk), [privacy](https://www.traceloop.com/docs/openllmetry/privacy/traces) and [configuration](https://www.traceloop.com/docs/openllmetry/configuration) review. Sentinel tests must cover every field/event/resource/status path, not merely config flags.
