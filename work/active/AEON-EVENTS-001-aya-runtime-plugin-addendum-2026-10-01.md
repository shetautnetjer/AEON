The Paperclip agent ID is an execution principal, distinct from a Brainstem profile binding. Record the mapping in the existing task/owner contract after approval; Paperclip assignee changes do not automatically confer private-memory access. Before integration cutover, choose one live task authority and reconcile retained task/attempt/event checkpoints; AEON's index remains a projection, not a second queue.
